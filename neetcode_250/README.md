# NeetCode 250

A Python practice workspace for the [NeetCode 250 study plan](https://neetcode.io/practice/practice/neetcode250). Problems are grouped by topic. Each problem directory contains a solution scaffold and a test scaffold.

## Repository layout

```text
neetcode_250/
├── README.md
└── <topic>/
    └── <problem-slug>/
        ├── solution.py
        └── test_solution.py
```

## Working on a problem

1. Open the problem directory under its topic folder.
2. Implement the required method in `solution.py`.
3. Add examples and edge cases to `test_solution.py`.
4. Run the tests from that problem directory:

   ```bash
   python -m unittest
   ```

The solution and test files are intentionally unimplemented scaffolds. The starter test is skipped until problem-specific cases are added.
